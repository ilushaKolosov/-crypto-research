# Шумоподавление и утечка будущего

Синтетический ряд «случайное блуждание плюс шум», двусторонние и каузальные операторы очистки, точность знака следующего шага и проверка формулы по весам линейного оператора.

Запуск из этого каталога:

```
python leak_model.py
python table1.py
python table2_ml.py
python sheppard_check.py
python a1_extra.py
```

Начальные значения генератора зафиксированы в скриптах. `a1_extra.json` хранит сводку уже выполненного прогона.
