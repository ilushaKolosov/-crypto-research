# Маршрутизация с цепочкой подтверждения доставки

Патч симулятора The ONE: `the-one-patch/PoDC_the-one.patch`.

Тот же код предложен в проект: https://github.com/akeranen/the-one/pull/125

Готовые прогоны лежат в `results/`. Из этого каталога:

```
python podc_stats.py
python figs_10.py
```

`podc_stats.py` печатает средние, 95 % доверительные интервалы и парные тесты. `figs_10.py` строит графики доли доставки, объёма трафика и поведения при атаках. Прогон MaxProp при N = 150 и начальном значении 4 пустой: реализация MaxProp остановилась на ошибке сортировки, поэтому эта точка посчитана по девяти прогонам.

Новые прогоны запускаются из `scripts` после сборки The ONE. Каталог симулятора задаётся переменной `THE_ONE_HOME`. Если её нет, скрипт ищет соседний каталог `the-one`.
