# Свечи биткоина, режимы и решающее правило

Данные: `data/df_15min.csv.gz` и `data/df_1min.csv.gz`, январь 2021 г. — май 2025 г. Скрипты сами переходят в этот каталог.

```
python corrected.py
python a2_baselines.py
python a3_capital.py
python a3_tables.py
```

`corrected.py` обучает CatBoost по скользящим окнам. Это самый долгий шаг: каузальные режимы k-means, вневыборочные вероятности и факторный перебор метки режима и стекинга.

`a2_baselines.py` добавляет правила возврата и тренда, частоту роста внутри режима, логистическую регрессию и отдельную модель в каждом режиме.

`a3_capital.py` переводит выход классификатора в позицию и считает доходность в долях капитала. `a3_tables.py` печатает помесячные величины по файлу `a3_capital.pkl`.

Файлы `ablation_main.pkl`, `primary_main.pkl` и `a3_capital.pkl` относятся к сохранённому прогону. Перед новым запуском `corrected.py` их можно удалить.
